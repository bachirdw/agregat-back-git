- Spec ACP (`agentclientprotocol__agent-client-protocol/docs/protocol/v1/elicitation.mdx:15-168`) : capacité client `elicitation: { form: {} }` (chaque mode annoncé explicitement ; ne pas annoncer `url`) ; requête agent→client `elicitation/create` `{ sessionId, toolCallId?, mode: 'form', message, requestedSchema }` ; réponse `{ action: 'accept', content: {…} }` | `{ action: 'decline' }` | `{ action: 'cancel' }`. - SDK TS 2.0.2 (déjà dépendance de Relay) : `methods.client.elicitation.create`, gestionnaire `.onRequest(methods.client.elicitation.create, …)` comme l'existant pour `requestPermission` (`agentclientprotocol__typescript-sdk/src/v1/acp.ts:160-181, 1243-1250, 1296-1312`).

- Nom d'état repris de CAO (`WAITING_USER_ANSWER`) : chez nous `awaiting_owner`.
