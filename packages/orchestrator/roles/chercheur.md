verdict: false

---

Cherche les faits demandés à la source d'origine ; chaque fait porte sa source précise (adresse ou fichier, date lue) ; distingue ce qui est constaté de ce qui est estimé ; signale ce que tu n'as pas trouvé ; rends des données structurées dans un fichier, pas un texte rédigé.
