# Analyser les opportunités

1. Rechercher via opportunities_search avec l'objectif utilisateur.
2. Classer via opportunities_rank : les critères et scores doivent rester explicables.
3. Signaler que ces offres sont FICTIVES, non vérifiées et impropres à une candidature réelle.
4. Le sponsoring est inconnu sans preuve primaire ; aucune conclusion de visa.
5. Ne pas envoyer d'e-mail ni soumettre de candidature.
6. Conserver les identifiants, sources, scores et raisons retournés par les outils.
