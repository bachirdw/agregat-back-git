## Décisions et provenance

- API publique Playwright getByRef/normalize/click/JSHandle utilisée via playwright-core déjà épinglé ; aucune ligne de source externe copiée, aucune dépendance ajoutée. La séquence DOM conserve les quatre événements de pointeur/souris au centre puis el.click() dans une seule évaluation qui retourne sa propre preuve locale.
- force:true, le mode forced, observed(), le marqueur window et framenavigated comme preuve sont supprimés. Une attente de domcontentloaded est armée uniquement pour achever la navigation native d’un lien ou d’un formulaire après l’événement click déjà prouvé ; elle ne constitue jamais une preuve de clic. Le garde d’accord, l’aperçu d’envoi, la revalidation de la page/cible et le refus de ref périmée restent sur la même route gateway.
- Le clic normal Playwright reste l’action visible. Un témoin JSHandle local évite un second clic si Playwright expire après livraison ; il n’utilise pas le locator une fois l’action lancée. Alternative rejetée : considérer tout TimeoutError comme absence de clic.
- Les tests de clic passent par des refs ; les sélecteurs des fixtures ne servent qu’à trouver la ref d’accessibilité dans tests/support/click-ref.js. Une cible span sans ref a été migrée vers la ref du bouton parent. Le nouveau fichier Chrome est exécuté en série pour ne pas charger la phase parallèle.
