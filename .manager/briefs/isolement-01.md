## Constat (lu par l'audit)
Gemini reçoit une maison isolée par mission seulement avec une clé API. Claude Code (authentifié par compte) tourne avec le `HOME` réel : transcriptions de toutes les missions dans le même projet Claude Code (`cwd` unique), configuration personnelle du propriétaire (CLAUDE.md global, réglages, Skills, MCP) chargée à chaque mission. La mémoire automatique est déjà coupée (`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`), non vérifié côté adaptateur `claude-agent-acp`.

## But
