## Constats préalables (Skill, lu)

- `url-key.mjs` **n'est pas un script appelable** : aucun `isMainModule`/`process.argv`, seulement des exports (`normalizeUrl`, `postingKey`…). Il est utilisé par `merge-tracker`, `precheck-duplicate` et `scan.mjs`. Il ne peut donc pas entrer dans `career_script` ; la déduplication par clé d'URL passe par `precheck-duplicate --url` (lecture seule) et par `merge-tracker` (fusion).
- `reconcile-pipeline.mjs` : drapeaux `--dry-run`, `--pipeline <path>`, `--state <path>` ; sert au chemin batch (`batch-state.tsv` → Processed). `rank-pipeline.mjs` : `--limit`, `--cli`, `--model`, `--dry-run`, `--self-test` ; annote `rank:` sans jamais retirer une ligne ; il lance un CLI d'agent (jetons dépensés, opt-in).
- `modes/pipeline.md` : « Liveness sweep — Run this before processing any URLs » : le balayage `check-liveness` précède la boucle par URL ; `precheck-duplicate` n'est cité ni par `pipeline.md` ni par `auto-pipeline.md` (déjà noté par l'audit 01 §3 bis).
